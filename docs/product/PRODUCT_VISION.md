# 织枢 WeavePivot — 产品愿景 V1.1
> 2026-11-17 · 规划稿 · Primordial Weave

## 使命
让 macOS 上分散的复制、截图、文件暂存与处理操作成为自然、低干扰、可组合的连续体验。

## 产品定位
织枢是一款原生 macOS 桌面工作中枢，而非功能堆叠的工具箱。以「织岛（入口）—织台（承载）—织流（处理）」为统一交互模型。

## 品牌原则
- 织：连接分散的信息、文件和操作。
- 枢：在合适的时间提供合适的入口。
- 温润青玉：克制的东方美学，材质和动效服务可用性。
- 原生、离线优先、隐私可控、轻量、可扩展。

## 目标用户
1. 经常跨应用复制、整理素材的设计师和内容创作者。
2. 需要截图、代码片段和文件转换的开发者。
3. 追求高效且低打扰桌面体验的普通 macOS 用户。

## 关键体验
复制/截图 → 织岛轻提示 → 织台暂存 → 快捷处理 → 拖出或粘贴。应支持键盘优先、鼠标操作和多显示器。

## 核心差异
- 单一素材模型连接剪贴板、截图和文件。
- 刘海一体化视觉入口，同时兼容无刘海设备。
- 轻量预设工作流，减少跨应用窗口切换。
- 无需账户即可使用核心功能；敏感内容可过滤、删除或暂停记录。

## 不做什么
不替换系统 Dock、不依赖云端完成核心操作、不为装饰牺牲可读性、不承诺系统权限无法支持的能力。

## 成功指标（建议目标，待基线测试）
- 核心闭环可在一次连续操作中完成。
- 权限拒绝时提供清晰替代路径。
- 空闲 CPU、内存、启动耗时及截图响应均在目标设备上测量并形成发布门槛。
- 首批可用性测试用户能够独立完成复制、截图、暂存、拖出四类任务。

## 版本方向
V0.1：织岛、剪贴板、截图、织台闭环；V0.2：解压缩、图片转换、织流预设与经 PoC 验证可行的 Dock 预览；V0.3：织流可配置工作流与基础自动化；V1.0：稳定性、无障碍、扩展性和分发完善。

## 设计决策
视觉稿是方向而非系统 API 可行性的证明。正式开发前必须先验证刘海窗口、屏幕捕获、粘贴板与权限行为。

## V1.1 冻结的产品边界
- V0.1 的承诺只有：原生应用入口、织岛、文本与图片剪贴板历史、区域截图、织台暂存及复制/拖出、隐私控制与基础无障碍。文件/链接类型及高级搜索是增强项；可选 OCR、标注不阻塞发布。
- V0.1 内部 Task Engine 仅用于执行单步操作及进度反馈，**不等于面向用户的织流预设**。
- V0.2 才提供用户可见的织流预设；V0.3 才提供可配置工作流。Dock 预览仅在合法 API 和权限可行时提供，绝不替换系统 Dock。
- 所有版本必须具备基本隐私、无障碍、性能和异常恢复；V1.0 是成熟化，不是首次实施。
- 视觉上的刘海融合为优先体验目标，不承诺第三方软件可控制物理刘海；PoC 未通过时采用清晰标注的独立胶囊降级。
- 成功指标的量化阈值在真实设备 PoC 后制定；当前不将未经测量的数字作为验收事实。
