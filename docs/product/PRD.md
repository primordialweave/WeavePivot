# 织枢 WeavePivot — 产品需求文档 PRD V1.1
> 2026-11-17 · V0.1 MVP 范围 · 需求草案

## 1. 产品目标
验证「织岛唤起 → 复制/截图采集 → 织台暂存 → 处理 → 粘贴/拖出」闭环。所有功能离线优先，不要求登录。

## 2. 目标平台与约束
macOS 原生应用，SwiftUI + AppKit；最低支持系统版本在 PoC 后确定。适配刘海/无刘海、多显示器、Retina、浅深色模式。系统权限必须按需请求。

## 3. 用户故事与验收
### US-01 织岛
用户可通过快捷键唤起，刘海设备默认与黑色刘海视觉融合；无刘海设备使用顶部胶囊替代。
验收：默认不遮挡菜单栏关键项目；悬停/展开/收起状态可逆；全屏、不同屏幕与多桌面下行为明确；Esc 收起。

### US-02 剪贴板历史
用户复制文本、图片或文件引用后，可搜索、预览、复制回剪贴板或删除历史。
验收：重复项策略可配置；支持暂停记录、排除应用、清空历史；敏感内容默认谨慎处理；重启后持久化行为可配置。

### US-03 截图
用户可通过快捷键触发区域截图，并复制、保存或送入织台。
验收：权限未授权时显示解释与系统设置入口；多显示器坐标正确；取消截图不产生素材；失败有可恢复反馈。

### US-04 织台
用户能把截图、文字、文件、链接暂存到统一素材区，搜索、多选、预览和拖出。
验收：文件引用不被误删；源文件不可访问时明确提示；拖出使用系统兼容数据类型；可清理暂存。

### US-05 内部任务执行（V0.1）
V0.1 仅实现供截图、复制、导入等功能复用的内部任务状态与取消能力；不交付用户可见的多步织流预设。织流预设于 V0.2 交付，可配置工作流于 V0.3 交付。
验收：任务可报告状态、错误及可取消性；无权限时不静默失败。

## 4. 交互状态
织岛：隐藏/悬停/轻量展开/完整展开/任务进行中/完成反馈。以系统刘海为视觉锚点，但不试图改变物理刘海。动效尊重 Reduce Motion。
织台：网格/列表、空状态、搜索无结果、多选、拖入反馈、错误状态。
剪贴板：分类、搜索、详情、删除确认、暂停记录。
截图：区域选择、预览、复制、保存、加入织台、取消、权限拒绝。标注编辑为 V0.1 可选增强。

## 5. 数据与隐私
- 本地持久化；用户可控制保留数量与时间。
- 默认不上传剪贴板、截图或文件内容。
- 不记录密码等敏感内容的保证需依据实际检测能力限定；提供应用排除、暂停与一键清空。
- 所有文件处理操作明确输入、输出及是否覆盖源文件。

## 6. 权限与技术
截图：ScreenCaptureKit/系统截图能力；OCR：Vision；剪贴板：NSPasteboard；文件拖放：NSItemProvider、FileProvider 或 AppKit 适当 API。Dock 预览需单独验证 Accessibility/窗口缩略图的边界，不进入 V0.1。

## 7. 非功能需求
原生键盘操作、VoiceOver 标签、动态字体与对比度、减少动画、异常恢复、低空闲资源消耗、可诊断日志（不记录隐私内容）。性能阈值通过目标机器基准测试制定，不在需求阶段伪造数字。

## 8. 不在 V0.1 范围
完整 Dock 替换、压缩格式全集、云同步、账号系统、插件市场、复杂 AI、可视化任意工作流编辑器。

## 9. 发布验收门槛
四项核心用户任务通过端到端测试；权限允许/拒绝/撤回均覆盖；至少一台刘海设备及一台无刘海环境验证；多显示器与睡眠唤醒测试；数据清理与隐私开关可靠；崩溃和性能问题有记录及回归测试。

## 10. 待确认事项
最低 macOS 版本、Mac App Store 或独立分发、剪贴板持久化默认策略、图标与品牌资产最终版、许可证。以上决策冻结后更新本文件。

## 11. V1.1 需求等级与追踪
**Must**：阻塞 V0.1 发布；**Should**：V0.1 尽力实现，未完成可延期但须标明；**Could**：机会性增强；**Out**：明确排除。唯一版本与等级来源为 FEATURE_MATRIX；本 PRD 的验收只在对应功能实际纳入版本时生效。

## 12. 关键端到端场景
1. **剪贴板**：复制普通文本 → 采集历史 → 搜索 → 复制回 → 其他应用粘贴；复制图片执行同样闭环。系统来源应用无法可靠识别时不得伪造归属。
2. **截图**：用户主动唤起 → 按需说明权限 → 区域选择 → 预览 → 保存/复制/加入织台；Esc 取消，权限拒绝时提供恢复操作。
3. **织台**：从剪贴板/截图加入 → 预览 → 拖出 Finder 或目标应用 → 删除织台项但保留源文件。
4. **异常**：重启、源文件移动、权限撤回、屏幕切换、拖放取消、复制大量数据时不得静默丢失或阻塞主线程。

## 13. 数据生命周期的产品契约
默认本地保存历史，**默认保留期限和条数在 ADR-009 决定后冻结**。必须区分引用的外部文件与应用拥有的缓存。清空历史清理索引、拥有的二进制缓存和缩略图；不删除用户原始文件。排除应用属于尽力能力，不可可靠归因时以暂停采集为可靠替代；不声称自动识别所有密码。用户可以在设置查看保留策略、暂停、清空及授权说明。

## 14. 交付阻塞条件
未决 ADR-007（最低 macOS）、ADR-008（分发与沙盒）、ADR-009（保留默认值）不阻塞隔离 PoC，但阻塞正式发布配置冻结。PoC-NOTCH 失败时需明确批准降级。所有 Must 用例通过且没有 P0 安全/数据缺陷才能进入 Beta。
